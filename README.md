Automatización de Pruebas QA – Selenium & Cucumber

📌 Descripción del Proyecto

Este repositorio contiene un proyecto de automatización de pruebas desarrollado como parte del Curso de Control de Calidad (QA) impartido por STI Globals.
El proyecto se enfoca en la validación de la funcionalidad, usabilidad y estabilidad de una aplicación web mediante pruebas automatizadas utilizando Selenium WebDriver y Cucumber bajo el enfoque de Behavior Driven Development (BDD).

🎯 Objetivos

- Diseñar y ejecutar escenarios de prueba automatizados basados en requerimientos funcionales
- Validar el comportamiento del sistema utilizando el enfoque BDD (Given – When – Then)
- Identificar defectos, errores funcionales y fallas de validación
- Generar evidencia de pruebas y reportes para respaldar la calidad del software

🛠 Tecnologías y Herramientas

- Lenguaje de Programación: Java
- Framework de Automatización: Selenium WebDriver
- Framework BDD: Cucumber
- IDE: VIsual Studio
- Control de Versiones: Git y GitHub

🧪 Alcance de las Pruebas

Las pruebas automatizadas incluyen:

- Pruebas funcionales sobre páginas clave de la aplicación web
- Validación de flujos de usuario y navegación
- Verificación de mensajes de error y validaciones de campos
- Pruebas de regresión sobre funcionalidades críticas

▶️ Ejecución de las Pruebas

1. Clonar el repositorio: git clone https://github.com/KareliaAntunez/Quality-Assurance-.git
2. Abrir el proyecto en VIsual Studio
3. Instalar dependencias con Maven: mvn clean install
4. Ejecutar las pruebas: mvn test
